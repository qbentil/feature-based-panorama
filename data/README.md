# Sample images

These folders are **synthetic overlapping scenes** generated by
`scripts/generate_sample_images.py` so the panorama pipeline can run before you
shoot real phone photos.

They are good enough to develop and demo the app. Drop your own overlapping
phone photographs into the same folders when you have them; the pipeline does
not change.

## What is in each folder

| Folder | Contents | Why it is here |
|---|---|---|
| `scenes/scene_main/` | 5 overlapping courtyard views (~50% overlap) | Primary 3+ image panorama |
| `scenes/scene_viewpoint/` | Front, oblique, and side views of the same overlap | Viewpoint change |
| `scenes/scene_lighting/` | Daylight, shade gradient, dim | Illumination |
| `scenes/scene_second/` | 5 overlapping indoor noticeboard views | Extra scene so results are not one-set-only |

Rotation and scale robustness are **not** extra folders. Those are applied in
code from a main pair (15/30/45/90° and 0.5× / 0.75× / 1.5×).

## How to capture your own photos

- Phone camera is fine. Same zoom for a given scene. Hold the phone level.
- Stand in one place and rotate your body. Do not walk large steps sideways
  except for the viewpoint folder.
- Aim for **30–50% overlap** between neighbouring shots.
- Name files `01.jpg`, `02.jpg`, … left to right.

Replace images in the same folder names. The app and experiment script pick up
whatever JPEGs or PNGs are in the folder.

## Regenerating the synthetic set

```bash
python3 scripts/generate_sample_images.py
```
